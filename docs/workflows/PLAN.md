# Plan procedure

Read `AGENTS.md`, product/domain context, architecture decisions, and the relevant implementation and tests. Capture the goal, boundaries, numbered acceptance criteria, examples and negative cases, risks, verification, compatibility/recovery, and material unknowns. Create a GitHub issue or a local task from `docs/tasks/TEMPLATE.md`; record the plan revision and actual authorization source. For plan-only requests, stop after presenting the reviewable plan. If implementation is already authorized and the requirements are sufficient, proceed without redundant confirmation.
